# Заметки по ТЗ и лекции (Трек 2)

## Источник истины
Официальное ТЗ (ред. 2.0) и презентация «Постановка ТЗ». Устные пожелания лектора ниже ценны, но второстепенны.

## Обязательное (ТЗ, разделы 4 и 6)
- Путь: вход/гость → каталог → проект из фото (≥10, порядок, кадрирование) → автосохранение → проверка (разрешение, формат, пустые области) → корзина, тестовый промокод, заказ без списания → статусная лента → история и обращение в поддержку.
- ОТ-01…ОТ-08: запуск ≤15 мин или демо-ссылка, 2 роли с серверной проверкой, только синтетические данные, журнал действий, понятные ошибки, русский интерфейс, формулы и часовые пояса, список библиотек с лицензиями.
- МП-01…МП-06: каталог через API, JPEG/PNG, черновик, пересчёт цены, идемпотентность, удаление данных.
- Сдача: репозиторий, README, демо 5–7 мин + до 10 слайдов, схема архитектуры, API, данные, отчёт о тестах.
- Оценка: бизнес-задача 25, UX 20, данные/интеграции 15, техника 15, безопасность 15, масштаб 5, презентация 5. Неработающий основной сценарий = потолок 50/100.

## Из лекции (подтверждено со слов спикеров, не письменно)
- Приложение «зеркало сайта», быстрое и лёгкое; существующее приложение не брать в расчёт.
- Хотят «вкусный» путь и ИИ-возможности (правка фото, автомакет по пожеланию), но без тяжёлого редактора на устройстве.
- Боль клиента: бросает проект на этапе создания или корзины; хочет заказать «как выложить в соцсеть».
- Фотографы не целевая аудитория; цель — частные клиенты (Беларусь сейчас, РФ и СНГ позже).
- Внешние (в том числе санкционные) API разрешены; у компании возможны локальные модели (≈2×H200 в планах).
- Цвета бренда: жёлтый, чёрный, белый (корпоративные); у PicPac в вебе коралл на тёмном. Бренд-бука нет.

## Наблюдения по живому super.picpac.by
Витрина красивая, но «Создать фотокнигу» ведёт на вход и затем на старый сайт без ИИ: путь рвётся. Цена и срок видны сразу, есть «Подобрать по числу фото».
