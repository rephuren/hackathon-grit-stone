# Выбор трека

**Выбран Трек 2 (мобильное приложение picPac.by).** Решение команды, подтверждено лекцией.

| Критерий | Трек 1 (платформа) | Трек 2 (picPac) | Трек 3 (AI-ассистент) |
|---|---|---|---|
| Ценность для заказчика | средняя (нужны их процессы) | **высокая** («основная хотелка», монетизируемая) | высокая, но «инструмент» |
| Данные и интеграции | нужны 5 систем, мы их не знаем | **mock API достаточно** | нужен локальный LLM или API |
| Риск за 3 дня | высокий | **средний** | высокий (безопасность и LLM) |
| Видимость на демо | дашборд | **телефон в руках у жюри** | чат |
| Конкуренция | средняя | средняя | высокая (все делают ассистента) |

Остальные треки показываем одной идеей в конце питча (воронка = мостик к Треку 1; ассистент по статусам заказов = мостик к Треку 3).
