## 11.11.2026 — интерфейс по референсу и спецификации «Момент»
- Подтверждено пользователем: основной стиль жёлто-чёрно-белый, как на макете из 8 экранов. Токены взяты из VISUAL SPEC 0.1 (рабочая рекомендация команды, не утверждённый брендбук).
- Брендбук Pic Pac 2025: логотип красный #DD5757, шрифт сайта Futura PT, сезонные палитры. Маскотов в брендбуке нет; кот и робот перерисованы в SVG по макету. Гипотеза: заказчик примет жёлтый стиль «Фотопринта»; не подтверждено.
- Статусы заказа оставлены по ТЗ (принят → проверка → производство → готов/доставка → получен), а не как на макете.
- Идеи коллеги (AutoStory, Family Collect, Class Album) в код не внесены, кроме автоподбора числа страниц и сводки «Проверка фото». Решение по концепции за командой.

## 11.11.2026 — расширенная проверка качества
- По запросу пользователя добавлены: пересвет, обрезка важного объекта, неподходящий формат, массовое удаление дубликатов и неудачных снимков, плюс советы (контраст, шум, вытянутый кадр, сжатие, прозрачность).
- Обрезка важного объекта определяется эвристикой по контрасту, а не лицами: честно подписано в интерфейсе. Распознавание лиц возможно позже (локальная модель), решение за командой.
- Пороги подобраны на синтетических кадрах, на реальных фото их нужно откалибровать.

## 2026-11-11 · Закрыт общий доступ к тестовым аккаунтам
- Проблема: на экране входа публично подсказывался аккаунт `demo`/`demo123`; через публичную ссылку любой входил в него и видел чужие работы.
- Решение: подсказка убрана с экрана входа; пароли `demo`, `demo2` в рабочей базе заменены случайными, их сессии удалены. Оператор входит только по паролю из `.env` (`OPERATOR_PASSWORD`).
- Изоляция остальных пользователей (гости, Telegram) проверена: чужие проекты, фото и заказы отдают 404.
- Для демонстрации жюри: выдавать логин оператора отдельно; клиентский вход через Telegram или «Начать без регистрации».
- Общий демо-аккаунт для команды (11.11): логин `demo`, пароль в `app/.env` (`DEMO_PASSWORD`), выдаётся лично, на экране входа не показывается. Сброс в чистое состояние: `python scripts/reset_demo.py`.

## 2026-11-11 · AI-студия на локальной модели, список проектов, оформление v2
- AI-студия: Pollinations по русскому описанию рисовал не то, давал 1 картинку в 45 с на сервер и ставил водяной знак. Решение (согласовано): локальная LCM Dreamshaper v7 + перевод opus-mt-ru-en, фильтр контента, чистка запроса. Замер на M5/16 ГБ: загрузка 8 с, кадр 768×768 5–11 с, память 3,3 ГБ; выгрузка после 15 мин простоя. Pollinations остался запасным.
- Созданные кадры хранятся на сервере («Недавние кадры», 12 на пользователя): раньше терялись при выходе.
- Список проектов: черновики сверху, заказанные ниже и приглушены (просьба команды).
- Оформление v2 отдельным слоем с откатом одним переключателем (просьба: «с возможностью откатить»), палитра прежняя.
- Кота и робота нейросетью не заменяли: она не воспроизводит фирменного робота «Фотопринта», а подменять персонажей заказчика без оригиналов нельзя. Им добавлены объём (тени) и движение.

## 2026-11-11 — Оформления страниц фотокниги

Сделано: логотип из брендбука вместо текстового; заголовок «Твои фото — твоя история» в две строки без точек; новый Робо (глянцевый шлем, светящиеся глаза, наушники, жёлтый шарф) и обновлённый кот, персонажи больше не перекрываются белым блоком; меньше жёлтого в заставке; «Создать фотопродукцию»; компактная карточка «Продолжить проект» со статусом и «осталось добавить N фото»; иконка документа для статуса «Принят» (грузовик остаётся для «готов»); Manrope и шкала размеров из документа; знакомство с приложением из 4 шагов (после первого входа, повтор в Профиле).
