# HANDOFF — сводка для второго агента (Codex / kent), 12.11.2026

## Что это
PicPac «Момент» — мобильный заказ фотопродукции (Трек 2 хакатона «Фотопринт»): фото → автомакет → правки → проверка → тестовый заказ → статус. Telegram Mini App, браузер и PWA на одном коде.

## Запуск и проверка
- Запуск и тесты: `app/README.md`. Тесты: `cd app && .venv/bin/python -m pytest -q` (31 тест, все зелёные).
- Живой аудит стенда: `app/scripts/audit_live.py http://localhost:8010` (50 проверок).
- Стенд: Mac владельца, `scripts/tma_start.py` + Tailscale Funnel. Перезапуск — только по слову владельца.

## Где что лежит
- `app/backend/main.py` — API (проекты, фото, макет, заказы, оператор), журнал запросов в `data/app.log`.
- `app/backend/catalog.py` — продукты (фотокниги Lite/Classic/Premium/«Выпускной», календарь, фотохимическая и цифровая печать) и 12 «фотокниг по событиям» (mock API `/api/templates`).
- `app/backend/assistant.py` — помощник Робо: имитация Mary на открытой модели через Groq (`LLM_*` в `.env`), реальная Mary — `MARY_API_*`, без сети — правила.
- `app/backend/editcmd.py` — правка фото словами (`/api/edit-command`): текст → операции редактора.
- `app/frontend/app.js` — весь интерфейс; `styles.css` — базовые стили; `design.css` — оформление v2/v3; `theme.css` — тёмная тема, iPhone (шапка под чёлкой), последние правки.

## Что сделано сегодня (кратко)
Каталог как на picpac.by; календарь с сеткой дат; пустая корзина; холст: фото двигается пальцем, «Оригинал» отдельной кнопкой; ползунки только за кружок; мягкие советы по качеству (переключатель в профиле); статусы загрузки и «Повторить»; «Моменты» — выбранные из галереи фото раскладываются по папкам (Путешествие, Выходные, Встреча с друзьями) по дате и месту съёмки; правка фото словами; ИИ-помощник (Mary через Groq); тёмная тема (как в системе / светлая / тёмная, карточки как в Telegram); одна жёлтая палитра; PWA; шапка под чёлкой на iPhone. Подробно: `AUDIT.md` в корне и `git log`.

## Не сделано и ограничения
- Добавлять предметы в фото словами («добавь шапку») локальная модель не умеет — помечено «в разработке».
- Перестановка фото — стрелками, перетаскивания нет.
- PWA на устройстве и Android не проверены; жесты проверены в симуляторе и эмуляции.
- «Моменты»: браузер не видит альбомы телефона, папки строятся по EXIF/дате файла; названия — подсказка.
- Шаблоны и цены — mock (не реальный API picpac.by), заказ тестовый.

## Правила совместной работы
1. Перед правками: `python3 tools/team.py status`, затем `python3 tools/team.py start kent "задача" файлы...`; после — `finish kent`.
2. Работа в ветках `feature/*` через Pull Request; перед пушем `pytest`.
3. Не коммитить: `app/.env`, `app/data/`, `app/frontend/img/events/` (обложки — материалы заказчика), ключи и токены.
4. Основной агент (sasha) правит `app/frontend` — перед правкой этих файлов напиши в inbox: `python3 tools/team.py say kent sasha "..."`.
