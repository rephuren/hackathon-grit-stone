# Риски и технический долг

| Риск | Вероятность / влияние | Что делаем |
|---|---|---|
| Mini App не открывается у жюри (нужны Telegram, бот, HTTPS) | средняя / высокое | режим в обычном браузере по ссылке, запасной стенд, запись экрана |
| Бесплатный хостинг «засыпает» или меняет адрес | высокая / среднее | Cloudflare Tunnel для демо + запасной Hugging Face Spaces, прогрев перед выступлением |
| HEIC и большие фото на слабой сети | высокая / среднее | реальное тестирование на iPhone, сжатие и повтор загрузки (WP2) |
| Генеративная правка недоступна на демо | средняя / среднее | локальная модель и заранее заготовленный результат; без AI путь всё равно проходит |
| Ложные срабатывания «дубликат» | средняя / низкое | уже добавлены яркость и пропорции; позже более сильный хэш |
| Бренд, маскоты (кот и робот) без разрешения | средняя / среднее | не копируем бренд-персонажей; запросить бренд-бук |
| Слабое место по ТЗ: данные каталога | низкая / низкое | 5 продуктов с вариантами синтетически, документированы допущения |
| Утечка секретов (токен бота, `APP_SECRET`) | низкая / критичное | только окружение, `.env` в `.gitignore`; на стенде `SEED_TEST_USERS=0` |
| Жюри не поймёт «без ИИ» | средняя / среднее | объяснить: детерминированные проверки там, где ИИ не нужен; модель подключаема, локальная правка в плане |

## Технический долг
Нет ограничения частоты запросов; SQLite и один процесс; сессии без отзыва по устройству; авто-тестов UI нет (только API); подписанные ссылки действуют 1 час; логи без ротации.
