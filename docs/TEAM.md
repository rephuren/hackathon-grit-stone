# TEAM.md — общая доска команды (picPac «Момент»)

Обновляем по ходу работы. Одна строка = одна задача. Берёте задачу: ставите своё имя и статус `в работе`. Закончили: `готово` и номер PR.
Статусы: `свободно` · `в работе` · `на проверке` · `готово` · `блок`.

## Как работаем одновременно
- Ветки: `feature/<кратко>` от `main`. В `main` только через Pull Request, второй человек смотрит diff.
- Перед пушем: `cd app && .venv/bin/python -m pytest -q`.
- «Горячие» файлы: `app/frontend/app.js`, `app/backend/main.py`, `app/frontend/design.css`. Если правите их, запишите в таблицу ниже. Не правьте один и тот же файл параллельно без договорённости.
- Мелкие независимые изменения лучше, чем один огромный PR. Чаще подтягивайте `main` (`git pull --rebase origin main`).
- Секреты и `app/data/` не коммитим. Материалы заказчика (PDF/DOCX) лежат на общем диске, не в git.
