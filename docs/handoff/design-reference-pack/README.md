# PicPac: пакет дизайн-референсов для реализации

Этот каталог содержит визуальную передачу для точечного обновления интерфейса PicPac. Это не промпт и не требование переписать приложение.

## Что менять

- цветовую систему;
- типографику;
- поверхности, границы, тени и состояния;
- светлую и тёмную темы;
- единообразие нижней навигации, карточек, кнопок и переключателей.

## Что сохранять

- текущую структуру экранов и пользовательские сценарии;
- существующую логику, API и сохранение состояния;
- порядок и назначение действий;
- русские тексты, если отдельная задача не требует их исправить;
- доступность и работу на ширинах 360-390 px;
- белый цвет бумажного разворота в редакторе даже в тёмной теме.

## Состав

- `references/light/` - четыре целевых светлых экрана;
- `references/dark/` - четыре целевых тёмных экрана;
- `source-screenshots/` - восемь исходных снимков текущего приложения;
- `REFERENCE_MAP.md` - соответствие исходников и референсов;
- `DESIGN_TOKENS.md` - цвета, типографика и состояния;
- `IMPLEMENTATION_TASKS.md` - задачи и критерии приёмки.

## Важные ограничения

Референсы показывают направление, но не являются пиксельным макетом. Иллюстрация робота и рукописный логотип на них - визуальная имитация. В коде нужно использовать существующие фирменные ассеты или официальный логотип, когда он будет предоставлен.

PDF/DOCX заказчика в GitHub не добавлены согласно правилам репозитория. Из брендбука в этот пакет перенесены только применимые дизайн-токены и выводы.
